### 📸 Prompt 2: Sistema de Especificación de Assets (Tu flujo de trabajo)
**Objetivo:** Que la web genere automáticamente una "Lista de Capturas" para que sepas qué fotografiar en los motores.

```markdown
# ROL: Technical Artist & Content Manager
# TAREA: Implementar Sistema de Requerimientos de Imágenes

Necesito un sistema que me diga exactamente qué capturas de pantalla debo tomar en Roblox Studio y UE5 para cada lección.

## Funcionalidad:
1. **Frontmatter en MDX:** Cada archivo de lección debe tener un campo `requiredAssets` en su frontmatter.
   Ejemplo:
   ```yaml
   requiredAssets:
     - id: "ue5_mes2_01"
       description: "Captura del Viewport mostrando el Actor con el script Lua asignado en el Details Panel"
       engine: "UE5"
       resolution: "1920x1080"
     - id: "rbx_mes1_03"
       description: "Captura del Output de Roblox Studio mostrando el print() de la tabla de inventario"
       engine: "Roblox"
   ```

2. **Página de Producción (`/production`):** Una ruta privada que escanee todo el contenido y genere un **Checklist de Assets Faltantes**.
   - Debe mostrar: ID, Descripción, Motor, Estado (Pendiente/Completado).
   - Debe permitir marcar como "Subido" cuando yo coloque el archivo en la carpeta pública.

3. **Componente `AssetPlaceholder`:** En las lecciones, si la imagen no existe, mostrar un cuadro gris con la descripción de qué captura se necesita. Si existe, mostrar la imagen real.

## Acción:
Genera el código para este sistema de gestión de assets. Quiero poder ver una lista clara de "Tareas de Captura" antes de empezar a escribir el contenido visual.
```
