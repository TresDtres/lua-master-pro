## 🎯 Características del Sistema de Quiz

### Tipos de Preguntas

| Tipo | Descripción | Ejemplo |
|------|-------------|---------|
| **Teórica** | Conceptos y definiciones | "¿Qué es un GameMode?" |
| **Práctica** | Código y sintaxis | "¿Cómo se declara una variable local?" |
| **Análisis** | Interpretar código | "¿Qué imprime este código?" |
| **Aplicación** | Aplicar conceptos | "¿Qué usarías para...?" |

### Sistema de Validación

- ✅ **Respuesta correcta** → Verde, +puntos
- ❌ **Respuesta incorrecta** → Rojo, muestra la correcta
- 📝 **Explicación detallada** después de cada respuesta

### Puntuación

| Puntuación | Mensaje | Color |
|------------|---------|-------|
| ≥ 80% (12+/15) | "¡Excelente! 🎉" | Verde |
| ≥ 60% (9+/15) | "Bien hecho ✓" | Amarillo |
| < 60% | "Necesitas practicar 📚" | Rojo |

## 🔧 Cómo Funciona

### 1. El Estudiante Selecciona un Módulo

```
/quiz
  ↓
Grid con 12 módulos
  ↓
Click en "mes-07: Multijugador"
```

### 2. Carga las 15 Preguntas del Módulo

```typescript
const questions = getQuizQuestions("mes-07");
// Retorna 15 preguntas específicas del módulo 7
```

### 3. Responde las Preguntas

```
Pregunta 1 de 15
  ↓
Selecciona una opción
  ↓
Click en "Siguiente"
  ↓
Feedback inmediato (✓/✗ + explicación)
```

### 4. Ve Resultados Finales

```
┌─────────────────────────────────┐
│         87%                     │
│     13 de 15 correctas          │
│                                 │
│      ¡Excelente! 🎉             │
│                                 │
│  [Reintentar]  [Volver]         │
└─────────────────────────────────┘
```
