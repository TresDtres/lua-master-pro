# Introducción

La seguridad en Roblox es primordial. Lo que hace un hacker en su cliente no debe afectar al servidor. Este mes aprenderás a cruzar la frontera Cliente-Servidor usando **Remotes**, el equivalente al sistema de RPCs de otros motores.
