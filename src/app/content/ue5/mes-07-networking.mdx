# Introducción

Entramos en la Fase III: Nivel Avanzado. El desarrollo multijugador es uno de los desafíos más grandes en videojuegos. Unreal Engine tiene un sistema de replicación robusto, y en este mes aprenderás a controlarlo desde Lua. Entenderás conceptos como "Authority", "Replication" y "RPCs" para crear experiencias compartidas.

## Configuración del Entorno

Para probar multijugador, necesitarás configurar tu editor para lanzar múltiples instancias.

<CodeSnippet label="Configuración de Editor">
Editor Preferences > Level Editor > Play > Multiplayer Options > Number of Players: 2
</CodeSnippet>

También es útil configurar el modo de red para simular latencia (lag) y ver cómo se comporta tu código Lua.

<CodeSnippet label="Comando de Consola (Simular Lag)">
Net PktLag=100
</CodeSnippet>
